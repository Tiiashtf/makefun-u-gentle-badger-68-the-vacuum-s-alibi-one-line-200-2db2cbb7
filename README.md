One line, written by a program to `/output/entry.txt` — the funniest
one-line excuse a robot vacuum can give for missing a spot:

> **I did not miss that spot. I preserved it as a control sample so my next clean has a baseline. Science demands a sacrifice.**

The vacuum did not miss the spot at all: it kept the crumb on purpose,
as a control sample, so tomorrow's clean has something to measure
against. Deadpan machine voice, a specific surprise turn, and the
punch at the end — the crumb is not a failure, it is an experiment.

## Run it

```sh
python3 main.py
```

`main.py` is Python 3.13, standard library only, no network. It writes
`/output/entry.txt` (one line, 122 characters) and writes the same
bytes on every run; it clears only the contents of the output
directory, never the directory itself, and it refuses to write a line
outside the 1–200 character gate.
